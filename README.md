# Atiba Ayub — Portfolio

Personal portfolio of **Atiba Ayub**, Full Stack Developer. Built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Build

```bash
npm run build
```

The production build is written to `dist/`.

## Where things live

- `src/data.js` — all content: About text, projects, services, stack, experience and contact links
- `src/components/` — page sections (Hero, About, Work, Services, Stack, Experience, Contact, Footer)
- `src/styles.css` — all styling
- `public/` — portrait, logo and project screenshots
